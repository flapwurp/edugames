Zwei iPads, ein Raum

Ein iPad öffnet einen Raum, das zweite gibt den Code ein. Danach sieht jedes Gerät in Echtzeit, wo auf dem anderen getippt und gewischt wird. Oben steht die gemessene Verzögerung.

Übertragen werden nur der Raumcode, eine zufällige Gerätekennung und Fingerpositionen, über Supabase (Server in Frankfurt). Nichts wird gespeichert, keine Namen, kein Login.
