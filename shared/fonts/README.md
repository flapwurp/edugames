# Schriften

Die Spiele laden Schriften nur aus diesem Ordner, nicht von Google-Servern (Datenschutz).
Fehlen die Dateien, nutzen die Spiele automatisch die Systemschriften des iPads.

Benötigte Dateien (alle unter der freien SIL Open Font License, Download über fonts.google.com
oder fontsource.org, Format `.woff2`):

| Dateiname | Schrift | Genutzt in |
|---|---|---|
| `bungee-400.woff2` | Bungee Regular | Who is it? |
| `nunito-variable.woff2` | Nunito (variable) | Who is it? |
| `atkinson-hyperlegible-400.woff2` | Atkinson Hyperlegible Regular | Reactor Rescue |
| `atkinson-hyperlegible-700.woff2` | Atkinson Hyperlegible Bold | Reactor Rescue |
| `chakra-petch-500.woff2` | Chakra Petch Medium | Reactor Rescue |
| `chakra-petch-700.woff2` | Chakra Petch Bold | Reactor Rescue |
